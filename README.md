# Detection-as-Code

A collection of Sigma rules I write to detect attacks in Windows, Active Directory and Linux logs.

## Goal

Put into practice what I learned in the TryHackMe SOC modules by turning attacks into real detections that can be converted to Splunk and Elastic queries.

## Planned coverage

- Active Directory credential attacks (Kerberoasting, AS-REP Roasting, DCSync)
- Lateral movement (PsExec, WMI, Pass-the-Hash)
- Windows execution and persistence (PowerShell, scheduled tasks)
- Linux threats (reverse shells, SSH persistence)
